# Launcher endpoints

Served to the StarLoco Launcher (`StarLoco-Client/launcher/`).

| Path | Purpose |
|---|---|
| `status.php` | `{"login":bool,"game":bool,"players":int,"name":string}` — TCP probe of the login/game ports via `checkState()`, plus `COUNT(*) FROM world_accounts WHERE logged = 1`. |
| `news.php` | Latest `website_timeline_news` rows as JSON. Same table the portal's `?page=administration` writes to, so news is posted once and shows up in both places. |
| `manifest.json` | Generated by `StarLoco-Client/launcher/tools/build-manifest.js`. Upload it here. |
| `files/<relative/path>` | One copy of every client file, laid out exactly as in the client install tree. |

Deploy layout on the web host (matching `remoteBase` in `launcher.config.json`):

```
<docroot>/launcher/
├─ status.php
├─ news.php
├─ manifest.json          <- from dist-update/
└─ files/                 <- from dist-update/files/
   ├─ Dofus Retro.exe
   └─ resources/app/retroclient/...
```

`files/.htaccess` turns off script execution for the payload. On nginx, do the
equivalent — inside `location /launcher/files/`, do not pass anything to PHP-FPM.
